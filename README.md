# Carlos Arrarte — Portfolio

Static, responsive English-language portfolio ready for GitHub Pages.

## Publish on GitHub Pages
1. Sign in to GitHub as `carloschinga934-png`.
2. Create a **public** repository named **`carloschinga934-png.github.io`** (exactly).
3. Upload `index.html` and the entire `assets` folder to the root of the repository (not the ZIP file).
4. Open repository **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)** and save.
5. After GitHub publishes it, open `https://carloschinga934-png.github.io/` and verify the page, profile photo, and CV download.
6. Paste the published URL in Get on Board's portfolio field.
